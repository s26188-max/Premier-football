# ⚽ 프리미어 풋볼 3D

브라우저에서 바로 즐기는 3D 축구 리그 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

**▶ 플레이:** `https://YOUR-USERNAME.github.io/premier-football-3d/` (배포 후 주소로 교체하세요)

## 특징
- 8개 팀 리그(7라운드) · 순위표 · 우승팀 트로피 세리머니
- 난이도 3단계(쉬움 / 보통 / 잘함)
- 달리기(스태미나), 패스, 슛(파워 충전), 슬라이딩 태클, 드리블 기술(스텝오버·엘라스티코·마르세유 턴)
- 키퍼 다이빙, 심판(파울·옐로카드), 3인칭 프리킥과 수비벽
- 피파식 선수 카드, 라인업 **진화**, **이적시장**
- 관중석 약 2,800명, 모바일 터치 조작 지원

## 조작
| 동작 | 모바일 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 드래그 | WASD |
| 달리기 | 🏃 꾹 누르기 | Shift |
| 슛 | ⚽ 꾹 눌러 파워 충전 | Space |
| 패스 | 🎯 | E |
| 태클 | 🛡️ | Q |
| 드리블 기술 | 🔄 | F |

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다. (three.js와 폰트는 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 기술 정보
- [three.js](https://threejs.org/) r128 (cdnjs), Google Fonts(Jua)
- 진행 상황은 브라우저 `localStorage`에 저장됩니다.
